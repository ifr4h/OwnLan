## Current build decision

Do not build the whole vision now. Current focus is a focused MVP:

-   instructor/business setup
-   pupil import and management
-   smart diary
-   daily teaching workflow
-   complete-lesson flow
-   progress tracking
-   balances/basic finance
-   learner portal
-   travel awareness/conflict warnings
-   excellent responsive UX

Long-term moat = connected workflow + data + intelligent scheduling +
network effects + marketplace liquidity + distribution, not merely
feature count.
